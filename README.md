This screenshot shows the network adapter configuration on the DC01 server. The Ethernet Properties window displays the enabled networking components for the Intel(R) PRO/1000 MT Desktop Adapter, including IPv4, IPv6, Client for Microsoft Networks, and File and Printer Sharing. This screenshot shows the Server Manager dashboard on the DC01 server after assigning a static IP address. The Ethernet section now displays the configured IP address (192.168.1.10), confirming that the network settings have been successfully applied. This step is important because a Domain Controller requires a fixed IP for reliable DNS and Active Directory operations. The Server Manager panel also shows system details such as OS version, hardware specifications, firewall status, and a recent warning event from the Windows Time Service.
